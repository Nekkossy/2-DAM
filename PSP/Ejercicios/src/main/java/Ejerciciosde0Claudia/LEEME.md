# Paquete de ejercicios de concurrencia

Este paquete contiene cuatro ejercicios independientes, cada uno con su propio `main()` y comentarios explicativos.

## Contenido

- `CarreraEliminatorias.java`
- `JuegoPanuelo.java`
- `ConcursoPreguntas.java`
- `CarreraRelevos.java`
- `ENUNCIADOS.md`

## Cómo añadirlo a IntelliJ

1. Descomprime la carpeta.
2. Copia `src/main/java/Ejercicios` dentro de la carpeta `src/main/java` de tu proyecto.
3. Comprueba que todas las clases empiezan por `package Ejercicios;`.
4. Abre la clase que quieras probar y ejecuta su método `main()`.

Los ejemplos utilizan hilos virtuales (`Thread.ofVirtual()`), disponibles desde Java 21. Se recomienda ejecutar el proyecto con JDK 21 o superior.

## Importante

Son soluciones didácticas para practicar distintas formas de sincronización. Los tiempos aleatorios hacen que el resultado pueda cambiar en cada ejecución. Las propuestas no representan predicciones ni enunciados confirmados del examen.
